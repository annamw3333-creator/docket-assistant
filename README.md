# Docket Assistant

WordPress plugin for the Docket website chat.

## Download the zip

Use this file in WordPress: **Plugins → Add Plugin → Upload Plugin**.

**[Download docket-assistant.zip](https://github.com/annamw3333-creator/docket-assistant/archive/refs/heads/main.zip)**

After you activate it:

1. Open **Settings → Docket Assistant**
2. Paste your **Docket URL** and **Bot ID** from Docket → Add to site
3. Save. The chat bubble appears on every public page.
