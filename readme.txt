Adds a Docket website chat bubble to every public page. A Docket account is required.

== Description ==

Docket Assistant is a **connector for the Docket service**. It does not generate replies inside WordPress. After you paste your Docket URL and bot ID, visitors see a chat bubble. Opening it loads your published assistant in an iframe from your Docket desk.

**This plugin calls a third-party service (SaaS).**

* Service: the Docket URL you enter in Settings → Docket Assistant.
* What is sent: visitor chat messages, typed in the widget, to that Docket desk so the assistant can reply.
* Account: you must have a Docket account and a published assistant. The plugin does nothing until those two fields are saved.
* Look and knowledge (name, colors, policies) are stored on Docket. Change them there — you do not re-upload this plugin.
* No “powered by” link is printed on your public site.

Docket is a customer-experience lab: you mystery-shop an assistant, then put the same desk on the website. This plugin is the WordPress install path.

Before you submit this plugin to WordPress.org, replace `Contributors: docketassistant` in this file with your WordPress.org username.

== Installation ==

= From the WordPress Plugin Directory (once listed) =

1. In WordPress go to Plugins → Add Plugin.
2. Search for “Docket Assistant”.
3. Install and activate.
4. Open Settings → Docket Assistant.
5. Paste your **Docket URL** and **Bot ID** from Docket → Add to site.
6. Save. The bubble appears on every public page.

= Upload (works today, before directory listing) =

1. Download `docket-assistant.zip` from Docket → Add to site → WordPress.
2. In WordPress: Plugins → Add Plugin → Upload Plugin.
3. Choose the zip, install, and activate.
4. Open Settings → Docket Assistant.
5. Paste the Docket URL and Bot ID shown in Docket.
6. Save.

== Frequently Asked Questions ==

= Does this work without a Docket account? =

No. The plugin is a connector. Generate a desk in Docket first, then paste the URL and bot ID here.

= Where do visitor messages go? =

To the Docket URL you configure. Replies are generated by that service. Do not install this plugin unless you trust that desk.

= Can I change colors, the greeting, or the knowledge base from WordPress? =

No. Brand the assistant and edit its knowledge in Docket. The plugin only places the bubble.

= Does the plugin load remote JavaScript from Docket? =

No. The launcher script is included in this plugin. The chat panel is an iframe of your Docket widget — the same pattern as other hosted chat tools.

= Will this slow my site? =

The launcher is a small local file. The iframe loads only after a visitor opens the bubble.

= How do I remove it? =

Deactivate and delete the plugin. Uninstall also removes the saved URL and bot ID.
